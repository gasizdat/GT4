Support

Start with the user guide. If it doesn't answer your question, get in touch.

Contact

  • Email: gasizdat@gmail.com
  • Bug reports and feature requests: GitHub issues (needs a free GitHub account)

When reporting a problem, it helps to include:

  • the app version and whether you use Windows or Android;
  • what you did, what you expected, and what happened instead;
  • if the app crashed, the newest file from its CrashLogs folder (see below). Logs are never sent automatically.

Please don't send your project file unless you're comfortable sharing the family data in it.

Common questions

Where are my projects stored?

Each project is a .gt4 file in the GT4 folder inside your Documents folder. To back up a project, copy that file, or use 📤 Export → Export to .gt4 from the Families page.

Where are the crash logs on Windows?

Paste one of these into the File Explorer address bar:

  • %APPDATA%\GT4\CrashLogs
  • %LOCALAPPDATA%\Packages\gasizdat.GenealogyTree_25ksdz0mncfjg\LocalCache\Roaming\GT4\CrashLogs (where Windows may keep it for the Microsoft Store version)

How do I move my tree to another computer?

Export it to .gt4 (or copy the file from Documents\GT4), then on the other computer choose 📥 Import on the project list and pick the file. Family tree arrangements and hidden people are stored per device, so they don't travel with the file.

Can I use my tree in other genealogy software?

Yes. 📤 Export → Export to GEDCOM creates a .zip with a GEDCOM 5.5.1 file and its photos and attachments, which most genealogy programs can import.

I imported a GEDCOM file and the names look garbled.

When a file declares an ambiguous character set, the app asks for the Codepage it was written in. If the names come out garbled, the wrong one was picked: delete the imported project and import again with another codepage (for example, Windows-1251 for older Russian files).

I closed the app unexpectedly. Did I lose my work?

Open the project and check 📌 Revisions on the Families page. If the app kept an earlier copy, you can restore it from there.

Does the app need an internet connection?

No. It only goes online when a biography contains a web image or you click a web link in one. See the privacy policy.

Is it free?

Yes. There are no ads, subscriptions or in-app purchases, and the source code is available under the Apache License 2.0.
